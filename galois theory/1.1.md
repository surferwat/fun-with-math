Show that if $x$ and $y$ are any two (real) numbers, and if $s=x+y$, $p=xy$, then $s^2-4p \ge 0$. Thus if $s^2-4p<0$ the problem $s=x+y$, $p=xy$ has no (real) solution.

Let $s=x+y$, $p = xy$.
Then $s^2 - 4p = (x+y)^2 - 4(xy) = x^2 + 2xy + y^2 - 4xy = x^2 -2xy + y^2 = (x-y)^2$.
$(x-y)^2 \ge 0$ since the square of a number cannot be negative.
Therefore, $s^2 - 4p \ge 0$.

Notes
- This result then shows that the set of possible real numbers with a given sum and product is **non-empty only when the discriminant (i.e., s^2-4p) is non-negative**.
