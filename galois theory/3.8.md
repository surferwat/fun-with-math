Prove that if  $a_0$, $a_1$, $a_2$, ..., $a_n$ are rational numbers, if $\alpha$ is a $p$th root of unity $\alpha \ne 1$, and if $a_0 + a_1\alpha + a_2\alpha^2 + ... + a_n \alpha^n = a_0 + a_1\alpha^g + a_2 \alpha^{2g} + ... + a_n \alpha^{ng}$, then $a_0 + a_1 \alpha + a_2 \alpha^2 + ... + a_n \alpha^n$ is equal to a rational number. Use the fact that $\alpha$ is not the root of any nonzero polynomial of degree $< p - 1$ with integer coefficients. (This fact will be proved in $\S64$ and in Exercise 8 of the eighth set.)

We are given:
- $a_0$, $a_1$, ..., $a_n \in \mathbb{Q}$,
- $\alpha$ is a $p$th root of unity with $\alpha \ne 1$,
- and $a_0 + a_1 \alpha + a_2 \alpha^2 + ... + a_n \alpha^n = a_0 + a_1 \alpha^g + a_2 \alpha^{2g} + ... + a_n \alpha^{ng}$.

We are to prove that $S := a_0 + a_1 \alpha + ... + a_n \alpha^n$ is rational, using the fact that $\alpha$ is not a root of any nonzero polynomial of degree $< p -1$ with integer coefficients.

**Step 1: Rearranging the hypothesis**
Subtracting the two expressions gives: $\sum_{k=0}^n a_k(\alpha^k -\alpha^{kg}) = 0$.
The $k=0$ term vanishes, so $\sum_{k=1}^n a_k(\alpha^k - \alpha^{kg}) = 0$. 
Rewrite: $\sum_{k=1}^n a_k \alpha^k - \sum_{k=1}^n a_k \alpha^{kg} = 0$.

**Step 2: Interpreting the condition**
Let $S = \sum_{k=0}^n a_k \alpha^k$.
The given condition says that replacing $\alpha$ by $\alpha^g$ leaves the value unchanged: $S(\alpha) = S(\alpha^g)$.
Now, since $\alpha$ is a primitive $p$th root of unity (because it is a $p$th root different from $1$ and $p$ is prime), the numbers $\alpha$, $\alpha^2$, ..., $\alpha^{p-1}$ are precisely the nontrivial $p$th roots of unity.
Now apply the map: $\alpha^{k} \mapsto (\alpha^k)^g = \alpha^{kg}$.
But since multiplication by $g$ permutes the nonzero residues mod $p$, $kg$ (mod $p$) runs through all values $1,$ ..., $p-1$ exactly once as $k$ does.
So the set $\{ \alpha^{kg} : k = 1, ..., p-1 \}$ is exactly the same set as $\{ \alpha^1, \alpha^2,$ ..., $\alpha^{p-1}$}.
Nothing disappears. Nothing new appears. They are just rearranged.
Thus, the map $\alpha \mapsto \alpha^g$ permutes the primitive $p$th roots of unity.
So if $S(\alpha) = S(\alpha^g)$, then $S$ takes the same value of two conjugates of $\alpha$.
And because the conjugates are linearly independent over $\mathbb{Q}$, the only way this invariance can happen is if all nonconstant coefficients vanish.

**Step 3: Using the minimal polynomial fact**
We are told that: $\alpha$ is not a root of any nonzero polynomial of degree $< p- 1$ with integer coefficients.
This means the minimal polynomial of $\alpha$ over $\mathbb{Q}$ has degree at least $p-1$.
But the polynomial $1+x+x^2 + ... + x^{p-1}$ has degree $p-1$ and vanishes at every primitive $p$th root of unity, so this must be the minimal polynomial.
Hence, the degree of the field extension,  $[\mathbb{Q}(\alpha) : \mathbb{Q}] = p-1$.
Thus, $\{1, \alpha, \alpha^2, ... \alpha^{p-2}\}$ is a basis for $\mathbb{Q}(\alpha)$ over $\mathbb{Q}$.
Thus these powers are linearly independent over $\mathbb{Q}$.

**Step 4: Applying linear independence**
We may reduce the powers of $\alpha$ modulo $p$, since $\alpha^p = 1$. 
Thus we may assume $S = b_0 + b_1 \alpha + ... + b_{p-1} \alpha^{p-1}$ with $b_i \in \mathbb{Q}$.
Using $1 + \alpha + ... + \alpha^{p-1} = 0$, we can eliminate $\alpha^{p-1}$ in favor of lower powers.
Hence we may assume $S=c_0 + c_1 \alpha + ... + c_{p-2} \alpha^{p-2}$.
Now apply the hypothesis $S(\alpha) = S(\alpha^g)$: $c_0 + c_1 \alpha + ... + c_{p-2} \alpha^{p-2} = c_0 + c_1 \alpha^g + ... + c_{p-2} \alpha^{(p-2)g}$.
Subtract: $\sum_{k=1}^{p-2} c_k (\alpha^k - \alpha^{kg}) = 0$.
This is a linear relation over $\mathbb{Q}$ among $1, \alpha, \alpha^2, ..., \alpha^{p-2}$.
Since these are linearly independent over $\mathbb{Q}$, all coefficients must vanish.
Because multiplication by $g$ permutes the nonzero residues modulo $p$ $\{1, ..., p - 1\}$, the only way for this relation to hold - given linear independence - is: $c_1= c_2 = ... = c_{p-2} = 0$.
Thus, $S = c_0 \in \mathbb{Q}$.

**Final conclusion**
Therefore, $a_0 + a_1 \alpha + ... + a_n \alpha^n \in \mathbb{Q}$.
