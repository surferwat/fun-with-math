Let $f$ be a polynomial with coefficients in a field $K$. Let $f(x+h)$, which is a polynomial in two variables $x$ and $h$, be expanded $f(x+h)=A(x)+B(x)h + C(x)h^2 + ...$ as a polynomial in $h$ with coefficients that are polynomials in $x$. Then $A(x) = f(x)$. The coefficients $B(x)$ of $h$ by definition the derivative of $f(x)$ denoted $f'(x)$. Show that $f(x)$ divided by its greatest common divisor with $f'(x)$ has the same roots as $f(x)$ and has only simple roots.

Start with a polynomial $f \in K[x]$, the set of polynomials in the variable $x$ whose coefficients come from the field $K$. 
Write its factorization over a splitting field $L$ of $f$: $f(x) = c \prod_{i=1}^{r} (x - \alpha_i)^{m_i}$, where the $\alpha_i$ are distinct and $m_i \ge 1$.

**Step 1: Compute the derivative**
Using the product rule (or standard facts about derivatives of factored polynomials), we get: $f'(x) = c \sum_{i=1}^r m_i (x - \alpha_i)^{m_i-1} \prod_{j \ne i} (x- \alpha_j)^{m_j}$.
From this expression, observe: 
- if $m_i = 1$, then $(x- \alpha_i)$ does not divide $f'(x)$.
- if $m_i \ge 2$, then $(x-\alpha_i)^{m_i-1}$ divides every term, so $(x-\alpha_i)$ does divide $f'(x)$.
More precisely, the multiplicity of $\alpha_i$ as a root of $f'(x)$ is $m_i - 1$ when $m_i \ge 1$.
	
**Step 2: Compute the gcd**
From the above, the greatest common divisor is: $gcd(f, f') = \prod_{i=1}^r (x - \alpha_i)^{m_i-1}$.
(This includes only factors where $m_i \ge 2$); if $m_i = 1$, that factor does not appear.)

**Step 3: Divide $f$ by the gcd**
Now compute: $\frac{f(x)}{gcd(f,f')} = \frac{c \prod_{i=1}^r(x-\alpha_i)^{m_i}}{\prod_{i=1}^r(x-\alpha_i)^{m_i-1}} = c \prod_{i=1}^r (x - \alpha_i)$.

**Step 4: Analyze the result**
1. Same roots: The resulting polynomial has exactly the same roots $\alpha_i$, since every factor $(x-\alpha_i)$ still appears.
2. Simple roots: Each root now appears with multiplicity $1$ so all roots are simple.

**Final conclusion**
$\frac{f(x)}{gcd(f(x), f'(x))}$ has the same roots as $f(x)$, each with multiplicity $1$.
Thus, it has exactly the same roots as $f$, but all of them are simple.

Notes
- A splitting field is just the smallest field where your polynomial fully factors into linear pieces. A splitting field $L$ for $f$ is a bigger field (containing $K$) s.t.: 1) $f$ factors completely in $L$: $f(x) = c(x-\alpha_1)(x - \alpha_2)...(x-\alpha_n)$ where all the $\alpha_i$ are in $L$.
- $L$ is generated by those roots: $L = K(\alpha_1, \alpha_2, ..., \alpha_n)$ meaning: you only add exactly what you need include the roots - nothing extra. We want to talk about the roots of $f$ but those roots might not lie in $K$ so we move to a splitting field where: all roots exist, we can factor $f$ nicely. Example: $f(x) = x^2 - 2$ $K = \mathbb{Q}$, roots: $\pm \sqrt{2}$ not in $\mathbb{Q}$ so we extend to: $L = \mathbb{Q}(\sqrt{2})$.
- Write $f(x) = (x-\alpha_i)^{m_i}g(x)$ with $g(\alpha_i) \ne 0$. Differentiating gives $f'(x) = (x-\alpha_i)^{m_i-1}(m_i g(x) + (x-\alpha_i)g'(x))$.
- The bracket does not vanish at $x=\alpha_i$, so it is not divisible by $(x-\alpha_i)$. Hence exactly $m_i - 1$ copies of $(x-\alpha_i)$ factor out of $f'(x)$ so the multiplicity is $m_i - 1$.
- In a polynomial ring over a field, the gcd takes each irreducible factor with the smallest exponent appearing both polynomials. So compare exponents: in $f$: exponent of $(x-\alpha_i)$ is $m_i$, in $f'$: exponent is $m_i - 1$, so gcd takes: $min(m_i, m_i-1) = m_i - 1$. Thus, $gcd(f,f') = \prod_{i=1}^r (x - \alpha_i)^{m_i-1}$.
- The key takeaway of this problem is $gcd(f, f') \ne 1 \iff$ $f$ has a repeated root. So instead of factoring $f$, you can detect repetition purely algebraically using $f'$. That's powerful because factoring is hard, gcd + derivative is much easier to compute. In Galois theory, a polynomial is called separale if it has no repeated roots. This problem shows: separability $\iff gcd(f,f') = 1$.
