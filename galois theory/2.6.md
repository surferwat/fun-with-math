In the notation of Exercise 5, show that if $t_1 = \pm t_2$ or $\pm t_3$ then two roots of the original equation are equal.

Let $t_1= x-y+z-r$, $t_2 = x+y-z-r$, $t_3 = x-y-z+r$
Let 
$x = \frac{1}{4}[(x+y+z+r) + t_1 + t_2 + t_3]$
$y = \frac{1}{4}[(x+y+z+r) - t_1 + t_2 - t_3]$
$z = \frac{1}{4}[(x+y+z+r) + t_1 - t_2 - t_3]$
$r = \frac{1}{4}[(x+y+z+r) - t_1 - t_2 + t_3]$

Let $t_1 = t_2$.
Then, $y = \frac{1}{4}[(x+y+z+r) - t_1 + t_2 - t_3] = \frac{1}{4}[(x+y+z+r) - t_3]$ and $z = \frac{1}{4}[(x+y+z+r) + t_1 - t_2 - t_3] =  \frac{1}{4}[(x+y+z+r) - t_3]$, so $y = z$.

Let $t_1 = -t_2$.
Then, $x = \frac{1}{4}[(x+y+z+r) + t_1 + t_2 + t_3] = \frac{1}{4}[(x+y+z+r) + t_3]$ and $r = \frac{1}{4}[(x+y+z+r) - t_1 - t_2 + t_3] = \frac{1}{4}[(x+y+z+r) + t_3]$, so $x = r$.

Notes
- The significance of this problem in a Galois-theory context is that it's teaching you how multiple roots, resolvents, and symmetry are tied together - and how degeneracies show up algebraically.
- You're thinking of the linear map $(x,y,z,r) \mapsto (t_1, t_2, t_3)$ with $t_1 = x - y + z - r$, $t_2 = x + y - z - r$, $t_3 = x-y -z + r$. This map takes the space of root configurations and records three independent "contrast directions" between roots. Crucially: the missing 4th direction is $S = x + y + z$, so $(S, t_1, t_2, t_3)$ together give all information. 
	- Generic root s= full freedom in resolvent space. When the roots are all distinct, there is no constraint tying $x,y,z,r$ together. So, you can move in all four directions, $(S, t_1, t_2, t_3)$ can vary freely, in particular, $(t_1, t_2, t_3)$ fill a 3-dimensional space. This is the "full values of the space" picture you're describing. 
	- Two equal roots = collapsing a direction. Now suppose two roots coincide, say $y=z$. That is a linear constraint on $(x,y,z,r): y -z = 0$. Geometrically: You're no longer in all of $\mathbb{A}^4$, the root space. You're in a 3-dimensional subspace (a hyperplane), the resolvent space. $\mathbb{A}^4 \to H := \{y=z\} \subset \mathbb{A^4}$. This is a restriction of the domain of the map $\phi$. When you push this hyperplane through the resolvent map, $\phi |_H : H \to \mathbb{A}^3$, something important happens. Nothing has been said about the image yet.
	- Computing the image of that restriction. Now we ask a different question: What does $\phi(H)$ look like inside $\mathbb{A}^3$? To answer that we plug $y=z$, then $t_1 = x - y + z - r = x - r$, $t_2 = x+y-z-r = x-r$ so automatically: $t_1 = t_2$ This means: the image of the "degenerate" root space lies inside the plane $t_1 = t_2$. So instead of filling all of $\mathbb{A}^3_{(t_1, t_2, t_3)}$, you only reach a 2-dimensional slice, $\phi(H) \subset \{ t_1 = t_2 \} \subset \mathbb{A}^3$. That's what you meant by only getting partial values of the space - and you're completely right.
	- The key equivalence. What makes this powerful is that the logic works both ways: if roots collide $\to$ resolvent image collapses. If resolvent image collapses $\to$  roots must have collided. So "losing independence" of resolvents is exactly the same thing as "losing degrees of freedom among the roots."
	- Why this is the right mental model. You should think of the $t_i$ as: coordinates measuring how much freedom the roots still have 1) distinct roots $\to$ full coordinate freedom, equal roots $\to$ some coordinates forced to agree, and more collisions $\to$ more collapse.
- One-line summary (your intuition, polished): The linear resolvents normally let the roots explore the full space of values, but when two roots coincide, one direction collapses and the resolvents can only reach a lower-dimensional subset.
