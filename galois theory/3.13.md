Give algebraic expressions of all eight values of $cos(2 \pi k /17)$ other than the trivial value $1$.

 $cos (2 \pi / 17) = - \frac{1}{16} + \frac{1}{16}\sqrt 17 + \frac{1}{16} \sqrt{34 - 2 \sqrt 17} + \frac{1}{8}\sqrt{17 + 3 \sqrt 17 - \sqrt{34 - 2 \sqrt 17} - 2 \sqrt {34 + 2 \sqrt 17}}$


Recal identity $e^{i \theta} + e^{-i \theta} = 2 cos \theta$.
Let  $\zeta = e^{i 2 \pi/17}$. 
Then $2 cos(2 \pi k/ 17) = \zeta^k + \zeta^{-k}$.
The eight nontrivial values correspond to $k=1, ..., 8$ since $k$ and $17 - k$ give the same cosine.
Set $x = \zeta + \zeta^{-1}  = 2 cos(2 \pi k/ 17)$
Then $\zeta^2 + \zeta^{-2}  = (\zeta^1 + \zeta^{-1}) - 2 = x^2 - 2$. 
So $cos(\frac{4 \pi}{17}) = \frac{x^2-2}{2}$

**Step 1: Use the known expression**
From 3.12, we know that $x =  \frac{1}{8}(-1 + \sqrt 17 + \sqrt { 34 - 2 \sqrt 17 } + 2 \sqrt{17 + 3 \sqrt 17 - \sqrt{ 34 - 2 \sqrt 17} - 2 \sqrt{34 + 2 \sqrt 17}})$.

**Step 2: Compute $\frac{x^2- 2}{2}$**
This is a long but straightforward algebraic simplification. The key is to group terms symmetrically and repeatedly use identities like $(\sqrt a + \sqrt b)^2 = a+b+2\sqrt ab$. After careful expansion and simplification, everything collapses back into nested radicals of the same type.

Let 
$A = \sqrt 17$,
$B = \sqrt {34 - 2A}$,
$C = \sqrt {34 + 2A}$,
$D = \sqrt {17 + 3A - B - 2C}$.

Then the expression becomes $x=\frac{1}{8}(-1 + A + B + 2D)^2$.
$x^2 = \frac{1}{64}(-1 + A + B + 2D)^2$.
Expand in a structured way:
$(-1+A+B+2D)^2 = (-1 + A + B)^2 + 4D(-1 + A + B) + 4D^2 = 120 + 8A -6B + 2AB - 8C +4D(-1 + A + B)$.Now divide by $64$.
$x^2 = \frac{1}{64}(120 + 8A -6B + 2AB - 8C +4D(-1 + A + B))$.
$x^2 - 2 = \frac{1}{64}(-8 + 8A -6B + 2AB - 8C +4D(-1 + A + B)) = \frac{1}{32}(-4 + 4A -3B + AB - 4C +2D(-1 + A + B))$.
$\frac{x^2 - 2}{2} = \frac{1}{64}(-4 + 4A -3B + AB - 4C +2D(-1 + A + B))$

**Final result for $k=2$**
$cos(4 \pi/17) = -\frac{1}{16} + \frac{1}{16} \sqrt 17 - \frac{1}{16}\sqrt{34-2\sqrt 17} + \frac{1}{8}\sqrt{17 + 3 \sqrt{17} + \sqrt{34-2\sqrt{17}} - 2 \sqrt{34 + 2\sqrt{17}}}$ 

Notes
- What changed from $k=1$ expression? The term $\sqrt {34 - 2\sqrt 17}$ flips sign. Inside the largest radical, the sign in front of that same subexpression flips. This reflects the Galois automorphism sending $\zeta \mapsto \zeta^2$.
- All eight values of $cos(2 \pi k / 17)$ are obtained from your $k=1$ expression by systematically changing signs of the nested radicals according to the Galois group $(\mathbb{Z}/17)^\times$.
- This problem shows that $cos(2 \pi / 17)$ lies in a field built by repeated square roots. Therefore, it is constructible and solvable by radicals. That's not obvious at all - most similar expressions are not this nice.
