Show that if $t=\alpha+ \beta \alpha^g + \beta^2 \alpha^{gg} + ...$ as in $\S24$ then $(p-1)^{-1}[s+(t_2t^{p-3})/s^{p-3} +(t_3t^{p-4})/s^{p-4} + ...]$ is a primitive $p$th root of unity for any solution $s$ of $s^{p-1} = t^{p-1}$.

Let $p$ be an odd prime, $\alpha$ a primitive $pth$ root of unity, and $g$ a primitive root mod $p$.
Let $\beta$ be a primitive $(p-1)$st root of unity and define $t= \alpha + \beta \alpha^g + \beta^2 \alpha^{g^2} + ... + \beta^{p-2} \alpha^{g^{p-2}}$.
As in $\S24$, under the automorphism $\sigma : \alpha \mapsto \alpha^g$, we have $\sigma(t) = \beta^{-1}t$. 
More generally, if $t_i$ denotes the expression obtained from $t$ by replacing $\beta$ with $\beta^i$, then $\sigma(t_i) = \beta^{-i} t_i$.
Hence each product $t_i t^{p-1^i}$ is fixed by $\sigma$ since $\sigma(t_i t^{p-1-i}) = (\beta^{-i} t_i)(\beta^{-(p-1-i)} t_i t^{p-1-i} = t_i t^{p-1-i}$, because $\beta^{p-1} = 1$.
Also $t^{p-1}$ is fixed by $\sigma$. Therefore, if $s$ satisfies $s^{p-1} = t^{p-1}$, then under $\sigma$, $s$ must be sent to another $(p-1)$st root of $t^{p-1}$. 
Thus $\sigma(s) = \beta^{-k} s$ for some integer $k$ (depending on the choice of $s$).

**Step 1: How the constructed expression $A$ transforms**
Consider $A = (p-1)^{-1}[s + \frac{t_2 t^{p-3}}{s^{p-3}} + \frac{t_3 t^{p-4}}{s^{p-4}} + ... + \frac{t_{p-1}}{s^{p-2}} ]$.
Using $\sigma(t_i) = \beta^{i}t_i$, $\sigma(t) = \beta^{-1}t$, $\sigma(s) = \beta^{-k}s$, the $ith$ summand transforms as $\sigma(\frac{t_i t^{p-1-i}}{s^{p-1-i}}) = \frac{\beta^{-i} t_i \beta^{-(p-1-i)} t^{p-1-i} }{\beta^{-k(p-1-i)s^{p-1-i}}} = \beta^{-k} \frac{t_i t^{p-1-i}}{s^{p-1-i}}$. Here again $\beta^{-(p-1)} = 1$.
Thus, every term in the bracket is multiplied by $\beta^{-k}$. 
Therefore, $\sigma(A) = \beta^{-k}A$ where $\sigma: \alpha \mapsto \alpha^g$. (1) 
Also, if $s^{p−1}=t^{p−1}$, then every solution is of the form $\beta^{−m}s$, $m=0,1,…,p−2$.
So, there are exactly $p-1$ possible choices for $s$.

**Step 2: What happens if we replace $s$ by $\beta^{−m}s$?**
Let $A^m$​ denote the value of the expression when $s$ is replaced by $\beta^{−m}s$.
Because every term in the bracket is homogeneous of degree $1$ in $s$, replacing $s$ by $\beta^{−m}s$ multiplies the entire bracket by $\beta^{−m}$.

Thus $A^m=\beta^{−m}A$. (2)
So the $p−1$ possible choices of $s$ give exactly the $p−1$ values.
A, $\beta^{−1}A$, $\beta^{−2}A$, … , $\beta^{−(p−2)}A$.
These are all distinct.

**Step 3. How $\sigma$ acts on these values**
From (1), $\sigma(A)=\beta^{−k}A$.
Applying $\sigma$ repeatedly, $\sigma^r(A)= \beta^{−kr}A$.
Since $g$ is primitive mod $p$, successive applications of $\sigma$ correspond to cycling through all substitutions: $\alpha \mapsto \alpha^g$, $\alpha^{g^2}$, ..., $\alpha^{g^{p-1}}=\alpha$.
Thus $\sigma$ permutes the $p$ conjugates of any $p$th root of unity cyclically.
But the values (2) are also permuted cyclically by $\sigma$: $A \mapsto \beta^{-k}A \mapsto \beta^{-2k}A \mapsto ...$.
Because $\beta$ has order $p-1$, this cycle has length $p-1$.

**Step 4. Counting the values**
Now observe:
- The construction gives $p−1$ distinct nonzero values.
- Under repeated substitution $\alpha \mapsto \alpha^g$, these values cycle through themselves
- After $p−1$ substitutions, we return to the starting value.

This is exactly the behavior of the non-trivial $p$th roots of unity: $\alpha$ ,$\alpha^2$, ..., $\alpha^{p-1}$.
There are exactly $p−1$ of them, and they are cyclically permuted by $\alpha \mapsto \alpha^g$.
Since our construction produces $p−1$ distinct numbers with exactly this same cyclic behavior, they must be precisely the non-trivial $p$th roots of unity.

**Step 5: Conclusion**
Thus, for any choice of $s$ satisfying $s^{p-1} = t^{p-1}$, the quantity $A = \frac{1}{p-1}[s + \frac{t_2t^{p-3}}{s^{p-3}} + \frac{t_3t^{p-4}}{s^{p-4}} + ...]$ is one of the non-trivial $p$th roots of unity.
Hence, it is a primitive $p$th root of unity.
