Let $u$ and $v$ be as in $\S14$ and find $uv$ and $u + v$ in terms of $\sigma_1 = x + y + z$, $\sigma_2 = xy + yz + zx$, and $\sigma_3 = xyz$.

$u = (x + \alpha y + \alpha^2 z)^3$
$v = (x + \alpha^2y +\alpha z)^3$

$uv$
$= (x + \alpha y + \alpha^2 z)^3(x + \alpha^2y +\alpha z)^3$
$= [(x + \alpha y + \alpha^2 z)(x + \alpha^2y +\alpha z)]^3$
$=\bigl[x^2+\alpha^2xy+\alpha xz+\alpha xy+\alpha^2 xz+\alpha^3 y^2+(\alpha+\alpha^2)yz+\alpha^3 z^2\bigr]^3$
$=\bigl[x^2-xz-xy+y^2-yz+z^2\bigr]^3$
$=\bigl[x^2+y^2+z^2-(xz+xy+yz)\bigr]^3$
$=\bigl[((x+y+z)(x+y+z)-2(xz+xy+yz))-(xz+xy+yz)\bigr]^3$ 
$=[(x+y+z)^2-3(xy+yz+zx)]^3$
$=(\sigma_1^2-3 \sigma_2)^3$

$u+v$
$= (x + \alpha y + \alpha^2 z)^3 + (x + \alpha^2 y + \alpha z)^3$
$= A^3 + B^3, \quad A = x + \alpha y + \alpha^2 z, \, B = x + \alpha^2 y + \alpha z$
$= (A + B)(A^2 - AB + B^2)$
$= (2x - y - z)(A^2 - AB + B^2)$
$= 2(x^3 + y^3 + z^3 - 3xyz) \quad \text{(using } \alpha^3 = 1 \text{ and } 1+\alpha+\alpha^2=0)$
$= 2(x+y+z)((x+y+z)^2 - 3(xy+yz+zx))$
$= 2\sigma_1(\sigma_1^2 - 3\sigma_2), \quad \sigma_1 = x+y+z, \ \sigma_2 = xy+yz+zx$








Newton's Theorem (p. 12) gives us the relation $s_2 - s_1\sigma_1 + 2\sigma_2 =0$ where $s_1 = x + y + z$ and $s_2 = x^2 + y^2 + z^2$.

Here $\alpha$ is a primitive cube root of unity: $\alpha + \alpha^2 + \alpha^3 = 0$ where $\alpha \ne 1$, $\alpha^3 = 1$, $\alpha + \alpha_2 = -1$.
