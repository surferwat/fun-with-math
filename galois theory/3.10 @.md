Use the method of $\S25$ to derive the formulas of $\S21$ for $\sqrt[5]1$. (In the first stage set $\gamma_1 = \alpha$ and $d=2$ to find a resolvent $t_1$ whose square is invariant under $S^2$ where $S: \alpha \to \alpha^2$. In the second stage set $\gamma_2 = \alpha + \alpha^4$, and $d=2$ to find a resolvent $t_2$ whose square is rational.)

Formulas of $\S21$
$\alpha = \frac{\sqrt5 - 1 \pm \sqrt {-2 \sqrt 5 - 10}}{4}, \frac{-\sqrt5 - 1 \pm \sqrt {2 \sqrt 5 - 10}}{4}$

The method of $\S25$ involves using Gauss's technique to construct a sequence of intermediate fields between the known field field $\mathbb{Q}$ and the unknown field $\mathbb{Q}(\alpha)$ and to regard the whole extension from $\mathbb{Q}$ to $\mathbb{Q}(\alpha)$ as being made up of a sequence of extensions in which one ascends the ladder of intermediate extensions.

Let $\alpha$ be a primitive fifth root of unity, so $\alpha^5=1$, $\alpha \ne 1$.
We want to derive the explicit expressions for $\alpha$ using Gauss's resolvent method described in $\S25$.
The automorphism used in the problem is $S : \alpha \to \alpha^2$.
Since $2^4 \equiv 1$  (mod $5$), $S$ has order $4$. Thus $\mathbb{Q} \subset \mathbb{Q}(\alpha + \alpha^4) \subset \mathbb{Q}(\alpha)$ and we construct the field tower with two quadratic extensions.

**Step 1: First stage**
Set $\gamma_1 = \alpha$, $d=2$.
We form the resolvent $t_1 = \gamma_1 + S^2(\gamma_1)$.
Because $S^2 : \alpha \to \alpha^4$, $t_1 = \alpha + \alpha^4$.
Now check invariance: 
$S(t_1) = \alpha^2 + \alpha^3$
$S^2(t_1) = \alpha^4 + \alpha = t_1$.
Thus $t_1$ is fixed by $S^2$. Hence $t_1^2$ is invariant under the full group generated by $S$, so it must lie in $\mathbb{Q}$.
Compute $t_1^2:$ $t_1^2 = (\alpha + \alpha^4)^2 = \alpha^2 + 2\alpha^5 + \alpha^8$.
Using $\alpha^5=1$, $\alpha^8 = \alpha^3$ we obtain $t_1^2 = \alpha^2 + \alpha^3 + 2$.
But from $1 + \alpha + \alpha^2 + \alpha^3 + \alpha^4 =0$ we get $\alpha^2 + \alpha^3 = -1 - (\alpha + \alpha^4) = -1 - t_1$.
Hence $t_1^2 = 1 - t_1$.
Therefore $t_1$ satisfies $t_1^2 + t_1 - 1 = 0$.
Solving $t_1 = \frac{-1 \pm \sqrt 5}{2}$.
Thus $\alpha + \alpha^4 = \frac{-1 \pm \sqrt 5}{2}$.

**Step 2: Second stage**
Now set $\gamma_2 = \alpha + \alpha^4$, $d =2$.
Define $t_2 = \alpha - \alpha^4$.
Then $t_2^2 = (\alpha - \alpha^4)^2 = \alpha^2 - 2 \alpha^5 + \alpha^8 = \alpha^2 + \alpha^3 -2$.
Using again $\alpha^2 + \alpha^3 = -1 - t_1$ we obtain $t_2^2 = -3-t_1$.
Substitute $t_1 = \frac{-1 \pm \sqrt 5}{2}$.
Then $t_2^2 = \frac{-5 \pm \sqrt 5}{2}$.
Thus, $t_2 = \sqrt{\frac{-5 \pm \sqrt 5}{2}}$.

**Step 3: Recovering $\alpha$**
We now have $\alpha + \alpha^4 = t_1$ and $\alpha - \alpha^4 = t_2$.
Adding, $2\alpha = t_1 + t_2$.
Hence $\alpha = \frac{t_1 + t_2}{2}$.
Substitute $t_1$ and $t_2$: $\alpha = \frac{-1 \pm \sqrt 5}{4} + \frac{1}{2}\sqrt {\frac{-5 \pm \sqrt 5}{2}}$.
Simplifying the radicals gives $\alpha = \frac{\sqrt5 - 1 \pm \sqrt {-2 \sqrt 5 - 10}}{4}, \frac{-\sqrt5 - 1 \pm \sqrt {2 \sqrt 5 - 10}}{4}$

**Conclusion**
Thus, we have found the fifth roots of unity $\alpha$ which arise from the two-step quadratic tower $\mathbb{Q} \subset \mathbb{Q}(\sqrt 5) \subset \mathbb{Q}(\alpha)$ constructed using Gauss's resolvent method.

Notes
- This problem is important because it illustrates one of the first major successes of algebraic number theory and Galois ideas: showing that the 5th roots of unity can be constructed using only square roots. It reflects work originally done by Gauss and is a classic example in Galois Theory.
- It shows how a complicated extension can be built from simple ones. The field containing a primitive 5th root of unity has degree $[\mathbb{Q}(\alpha) : \mathbb{Q}] = 4$. Instead of handling the whole extension at once, Gauss's method builds it as $\mathbb{Q} \subset \mathbb{Q}(\sqrt 5) \subset \mathbb{Q}(\alpha)$. Each step has degree 2.
- By introducing the intermediate field $\mathbb{Q}(\alpha + \alpha^4) = \mathbb{Q}(\sqrt 5)$, we split the problem into two quadratic extensions, each easy to handle: 1) solve $t_1^2 + t_1 -1 = 0$ to get $\alpha + \alpha^4$, 2) solve $t_2^2 \in \mathbb{Q}(\sqrt 5)$ to get $\alpha - \alpha^4$, 3) combine $t_1$ and $t_2$ to get $\alpha$.
