Show that if $K$ is a field, if $x_1$, $x_2$, $x_3$, ... is an infinite sequence of distinct elements of $K$, and if $F(A,B,C,...)$ is a nonzero polynomial in $n$ variables $A,B,C$, ... with coefficients in $K$, then it is possible to select values $A=x_j$, $B=x_k$, $C=x_m$, ... for the variables $A,B,C$, ... from the sequence $x_1$,$x_2$, $x_3$, ... so that $F(x_j, x_k, x_m, ...) \ne 0$. 

We argue by induction on the number of variables $n$.

The key idea: a nonzero polynomial in one variable has only finitely many roots in a field. We extend this idea variable-by-variable.

**Base Case ($n=1$)**
Let $F(A) \in K[A]$ be nonzero. Then $F$ has only finitely many roots in $K$.

Since the sequence $(x_i)$ contains infinitely many distinct elements, at most finitely many of them can be roots of $F$. Hence there exists some $x_j$ s.t. $F(x_j) \ne 0$.

**Inductive Step**
Assume the statement holds for polynomials in $n-1$ variables. Let $F(A_1, ..., A_n)$ be a nonzero polynomial in $n$ variables.
View $F$ as a polynomial in the last variable $A_n$: $F(A_1, ..., A_n) = \sum_{i=0}^d G_i(A_1, ..., A_{n-1}) A_n^i$, where each $G_i \in K[A_1, ..., A_{n-1}]$ and at least one $G_i$ is nonzero.
Since $F \ne 0$, there exists some index $r$ s.t. $G_r \not\equiv 0$.

**Step 1: Choose $A_1$, ..., $A_{n-1}$**
By the induction hypothesis applied to the nonzero polynomial $G_r$, we can choose values $A_1 = x_{j_1}, ..., A_{n-1} = x_{j_{n-1}}$ from the sequence such that $G_r(x_{j_1}, ..., x_{j_{n-1}}) \ne 0$.

**Step 2: Reduce to One Variable**
Now define a polynomial in one variable: $H(T) = F(x_{j_1}, ..., x_{j_{n-1}}, T)$. 
Because $G_r(x_{j_1}, ..., x_{j_{n-1}}) \ne 0$, this polynomial $H(T)$ is not identically zero.

**Step 3: Choose $A_n$**
Since $H(T) \in K[T]$ is nonzero, it has only finitely many roots. 
The sequence $(x_i)$ contains infinitely many distinct elements so there exists some $x_{j_n}$ s.t. $H(x_{j_n}) \ne 0$.

**Conclusion**
With this choice, $F(x_{j_1}, ..., x_{j_n}) \ne 0$.
This completes the induction.

Notes
- This problem looks technical, but it's expressing a very important general principle in algebra: a nonzero polynomial cannot vanish "everywhere" on a large set. It tells us that zero sets are "small". We proved that if we have infinitely many distinct elements in a field, then: 1) we can't plug them into a nonzero polynomial and always get 0 and 2) there is always some choice where the polynomial survives (is nonzero).
- This problem is a starting point of algebraic geometry where people think of: polynomials -> defining geometric shapes and solutions -> points on those shapes. Our result says "a nonzero polynomial cannot define the entire space". This is crucial otherwise geometry would collapse (everything would satisfy everything). In other words, a point with $F \ne 0$ shows where the shape is not and it helps prove the shape doesn't fill the whole space.

Corollary. If one can find a polynomial $t$ in the roots $x'$, $x''$, $x'''$, ... with the property that its $n!$ different permutations are not merely formally distinct (this would be easy to accomplish - for example by setting $t=x' + 2x'' + 3x''' + ...$) but also numerically distinct, then every permutation of the roots changes $t$ and the condition of Lagrange's theorem is met by all polynomials $y$. Therefore all polynomials in the roots, and, in particular, the roots themselves can be expressed rationally in terms of (any) one numerical value of $t$.

In short, if such a $t$ can be found, then it is a "resolvent" in the sense that (1) and (2) of $\S28$ are satisfied. Such a $t$ is called a "Galois resolvent" because Galois was the first* to realize that there always exist such $t's$ and to realize how useful they are in studying the solution of an equation even when they do not satisfy (3) of $\S28$. Of course it is impossible to find such a $t$ if two or more the roots $x'$, $x''$, ... coincide, so Galois must - and does - exclude equations in which this occurs. (This is not a real restriction because if $f(x) = 0$ has multiple roots then it has roots in common with $f'(x)=0$ and the greatest common divisor of $f$ and $f'$ which is a polynomial that can be found using the Euclidean algorithm ($\S35$), has as its roots the multiple roots of $f$; then $f$ divided by this greatest common divisor has the same roots as $f$ but they all occur with multiplicity $1$. See Exercise 2.)

Galois does not prove the existence of a Galois resolvent, he merely asserts it (see Appendix 1). Moreover, he asserts that there exist Galois resolvents of the special form $t=A'x' + A''x'' + A'''x''' + ...$ where the coefficients $A'$,$A''$, $A'''$, ..., are suitably chosen integers. This is certainly a plausible statement. Equality of two permutations of $A'x' + A''x'' + A'''x''' + ...$ is an exceptional circumstance, one that imposes a condition on the $A$'s. One need only choose the $A$'s in such a way that none of these conditions is satisfied. The proof which follows is a carrying out of this idea. Since Galois gives no indication at all of a proof, there isn no way of knowing whether this proof resembles what he had in mind.

Henceforth, let the $n$ roots of the given equation be denoted $a,b,c,$... The assumption is that these roots are distinct, which is to say that the discriminant $(a-b)^2(a-c)^2(b-c)^2 ... = D$ is not zero. (See $\S13$) What is to be shown is that $n$ integers $A$, $B$, $C$, ... can be chosen so that the $n!$ numbers $AS(a) + BS(b) + CS(c) + ...$ are distinct, where $S$ ranges over all $n!$ permutations of the roots $a,b,c$ ... Let $\mathcal{D}$ be the product of the squares of the differences of $n!$ numbers, that is $\mathcal{D} = \prod_{S,T} [A(S(a) - T(a)) + B(S(b) - T(b)) + ...]^2$, where the product is over all $n!(n! -1)/2$ pairs (unordered) of permutations $S$ and $T$ in which $S \ne T$. Let $A,B,C$,... be regarded at first as variables. Then $\mathcal{D}$ is a polynomial in $A,B,C$ ... whose coefficients are polynomials in the roots $a,b,c$... Since $\mathcal{D}$ is obviously symmetric in the roots, these coefficients are symmetric in the roots, so $\mathcal{D}$ is a polynomial in $A$, $B$, $C$, ... with known coefficients. Since $\mathcal{D}$ is a product of nonzero polynomials , it is nonzero (Exercise 4). Therefore (Exercise 3) one can assign integer values to $A,B,C$ ... in such a way as to make $\mathcal{D} \ne 0$, as was to be shown.
