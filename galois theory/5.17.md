Show that the automorphism of $K(a,b,c,...)$ over $K$ described in the first corollary of $\S41$ carries $t$ to $t'$.

Let $t = Aa + Bb + Cc + ...$, $A,B,C, ... \in K$, be the chosen Galois resolvent.
Let $S$ be the automorphism of $K(a,b,c, ...)$ over $K$ described in the first corollary of $\S41$, so that $S(a) = \phi_a(t')$, $S(b) = \phi_b(t')$, $S(c) = \phi_c(t')$, ...

Since $S$ fixes every element of $K$, $S(t) = AS(a) + BS(b) + CS(c) + ... = A\phi_a(t') + B\phi_b(t') + C \phi_c(t') + ...$.
Therefore, it is enough to prove $A\phi_a(t') + B\phi_b(t') + C \phi_c(t') + ... = t'$.

We know that  $a = \phi_a(t)$, $b = \phi_b(t)$, $c = \phi_c(t)$, ...
Thus,  $t = A\phi_a(t) + B\phi_b(t) + C \phi_c(t) + ...$.
Motivated by this identity, we define $P(X) = X - (A\phi_a(X) + B \phi_b(X) + C \phi_c(X) + ...)$.
Since $A,B,C, ... \in K$ and each $\phi_a(X), \phi_b(X), \phi_c(X)$, ... has coefficients in $K$, we have $P(X) \in K[X]$.
Moreover, $P(t) = t - (A\phi_a(t) + B\phi_b(t) + C \phi_c(t) + ...) = 0$.
We factor $P(X)$ into irreducible polynomials over $K$: $P(X) = G_1(X)G_2(X)... G_k(X)$.
Since $P(t)= G_1(t)G_2(t)... G_k(t) = 0$ and $K(a,b,c,...)$ is a field, at least one factor must vanish at $t$.
Thus for some $i$, $G_i(t) = 0$.
Because $G_i(X)$ is irreducible over $K$ and has $t$ as a root, its roots are the conjugates of $t$, including $t'$.
Therefore, $G_i(t')=0$.
Since $G_i(X)$ is a factor of $P(X)$, it follows that $G_i(X) \mid P(X)$, so every root of $G_i(X)$ is also a root of $P(X)$. 
In particular, $P(t')=0$.
Expanding this equality gives $t' - (A\phi_a(t') + B\phi_b(t') + C \phi_c(t') + ...) = 0$.
Therefore, $t' = A\phi_a(t') + B\phi_b(t') + C \phi_c(t') + ...$.

Combining this with our earlier computation of $S(t)$,  $S(t) = A\phi_a(t') + B\phi_b(t') + C \phi_c(t') + ... = t'$.
Therefore, $S(t) = t'$.

- Corollary from $\S41$. Let $t$ be a Galois resolvent, let $t'$ be one of its conjugates, and let $S$ be the substitution of the roots which carries the row of the above table $(1)$ corresponding to $t$ to the row corresponding to $t'$. In short, let $S(a) = \phi_a(t'), S(b) = \phi_b(t'), S(c)=\phi_c(t'), ...$ Then $S$ can be extended to an automorphism of the entire field $K(a,b,c,...)$ over $K$, that is a function $S$ from $K(a,b,c,...)$ to itself which is the identity map on $K$, which carries sums to sums, products to products, and agrees with the original $S$ for the roots $a,b,c,...$
