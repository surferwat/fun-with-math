Show that if $\alpha$ is a primitive $p$th root of unity ($p =$ prime) then the $p^{n-1}$st root of $\alpha$ is a primitive $p^n$th root of unity.

Let $\alpha$ be a primitive $p$th root of unity, so: $\alpha^p = 1$ and $\alpha \ne 1$.
Let $\beta$ be a $p^{n-1}$st root of $\alpha$, $i.e.$ $\beta^{p^{n-1}} = \alpha$.
We want to prove that $\beta$ is a primitive $p^n$th root of unity, meaning:
1. $\beta^{p^n} = 1$, and
2. the order of $\beta$ is exactly $p^n$.

**Step 1: Show $\beta^{p^n} = 1$**
Raise both sides of $\beta^{p^{n-1}} = \alpha$ to the $p$th power: $\beta^{p^n} = \alpha^p = 1$.
So $\beta$ is a $p^n$ th root of unity.
We still need to show that it is a primitive $p^n$ th root of unity.

**Step 2: Show the order is exactly $p^n$**
Let the order of $\beta$ be $m$. Then: $m | p^n$, so $m = p^k$ for some $k \le n$.
We need to show $k=n$.
Assume for contradiction that $k < n$. Then: $\beta^{p^k} = 1$.
Observe that $\beta^{p^{n-1}} = \alpha$. 
If $k < n$, then $k \le n - 1$ so $p^{n-1} = p^k \cdot p^{n-1-k} \Rightarrow p^k | p^{n-1}$, so : $\beta^{p^{n-1}} = \beta^{p^k\cdot p^{n-1-k}} = (\beta^{p^k})^{p^{n-1-k}} = 1$.
Thus: $\alpha = 1$, which contradicts the fact that $\alpha$ is a primitive $p$th root of unity.

**Conclusion**
The assumption $k < n$ is false, so $k=n$. Hence the order of $\beta$ is $p^n$, and therefore: $\beta$ is a primitive $p^n$th root of unity.

Notes
- For a prime $p$, $p^a | p^b$ if and only if $a \le b$ because $p^b = p^a \cdot p^{b-a}$ whenever $a \le b$ so $p^a$ divides $p^b$.
- This problem shows how roots of unity "build up" in towers. you start with a primitive $p$th root of unity $\alpha$, and then take a $p^{n-1}$st root of it to get a primitive $p^n$th root. So you can construct higher-order roots of unity step-by-step from lower ones. This reflects the structure of fields like: $\mathbb{Q}(\zeta_p) \subset \mathbb{Q}(\zeta_{p^2}) \subset ... \subset \mathbb{Q}(\zeta_{p^n})$.
