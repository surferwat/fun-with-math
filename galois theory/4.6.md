Find $(3+2\sqrt{2})^{-1}$ in the field $\mathbb{Q}(\sqrt{2})$ obtained by adjoining a root $\sqrt{2}$ of $x^2-2$ to the field $\mathbb{Q}$.

Work inside the field $\mathbb{Q}(\sqrt{2}) = \{ a + b \sqrt{2} | a,b \in \mathbb{Q}\}$.
We want $(3+2\sqrt{2})^{-1}$, the inverse of $3 + 2\sqrt{2}$, i.e., find an element $x = a+b\sqrt{2}$ such that $(3+2\sqrt{2})(a+b\sqrt{2})=1$.

**Step 1: Multiply out**
$(3+ 2\sqrt{2})(a+b\sqrt{2})$
$= 3a + 3b\sqrt{2} + 2a\sqrt{2} + 2b(\sqrt{2})^2$
$= 3a + 3b\sqrt{2}+2a\sqrt{2}+4b$.
$= (3a + 4b) + (3b + 2a)\sqrt{2}$.

**Step 2: Set equal to 1**
We need $(3a + 4b) + (3b + 2a)\sqrt{2} = 1 + 0\sqrt{2}$.
So we get the system: $3a+4b=1$, $3b+2a=0$.

**Step 3: Solve the system**
From $3b+2a=0$, we get $b = -2a/3$.
Substitute into the first equation:
$3a + 4(-\frac{2a}{3})=1$
$3a-\frac{8a}{3}=1$
$\frac{9a-8a}{3} = 1 \Rightarrow \frac{a}{3} = 1 \Rightarrow a = 3$.
Then $b = -\frac{2a}{3} = -2$

**Step 4: Final answer**
$(3+ 2\sqrt{2})^{-1} = 3 - 2\sqrt{2}$

Notes
- This problem shows how field extensions actually behave. We're working in $\mathbb{Q}(\sqrt{2})$ which is a field extension of $\mathbb{Q}$. The key point is: "Every nonzero element has an inverse that stays inside the field". This problem makes that concrete. You don't just accept the axiom - we see that $(3+2\sqrt{2})^{-1} = 3 - 2\sqrt{2}$ is still of the form $a+b\sqrt{2}$.
