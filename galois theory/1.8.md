Newton's objective in the passage where he gives the first set of formulas in $\S9$ is to determine, given two cubic polynomials, whether they have a common root. Let $f(x) = x^3 + bx^2 + cx + d$ have roots r, s, t as in $\S9$ and let $g(x) = x^3 + Bx^2 + Cx + D$. Then $g(x)$ and $f(x)$ have a root in common if and only if $g(r)g(s)g(t)=0$. Since $g(r)g(s)g(t)$ is a symmetric polynomial in $r$,$s$,$t$ whose coefficients are polynomials in $B$,$C$,$D$ with integer coefficients, this condition can be expressed in the form $P(b,c,d,B,C,D)=0$ where $P$ is a polynomial with integer coefficients. Find $P$. $[$An easy but slightly long computation. $P$ has $34$ terms]

Let $g(x)=x^3 + Bx^2 + Cx + D$.
Let $g(r)=r^3+Br^2+Cr+D$.
Let $g(s)=s^3+Bs^2+Cs+D$.
Let $g(t)=t^3+Bt^2+Ct+D$.
Then $g(r)g(s)g(t)= (r^3+Br^2+Cr+D)(s^3+Bs^2+Cs+D)(t^3+Bt^2+Ct+D)=0$.

We multiply out the three cubic polynomials:
$g(r)g(s)g(t)$
$=(r^3 + Br^2 + Cr + D)(s^3 + Bs^2 + Cs + D)(t^3 + Bt^2 + Ct + D)$
$= r^3 s^3 t^3 + B r^3 s^3 t^2 + C r^3 s^3 t + D r^3 s^3 + B r^3 s^2 t^3 + B^2 r^3 s^2 t^2 + B C r^3 s^2 t + B D r^3 s^2 + C r^3 s t^3 + B C r^3 s t^2$
$+ C^2 r^3 s t + C D r^3 s + D r^3 t^3 + B D r^3 t^2 + C D r^3 t + D^2 r^3 + B r^2 s^3 t^3 + B^2 r^2 s^3 t^2 + B C r^2 s^3 t + B D r^2 s^3$
$+ B^2 r^2 s^2 t^3 + B^3 r^2 s^2 t^2 + B^2 C r^2 s^2 t + B^2 D r^2 s^2 + B C r^2 s t^3 + B^2 C r^2 s t^2 + B C^2 r^2 s t + B C D r^2 s$
$+ B D r^2 t^3 + B^2 D r^2 t^2 + B C D r^2 t + B D^2 r^2 + C r s^3 t^3 + B C r s^3 t^2 + C^2 r s^3 t + C D r s^3 + B C r s^2 t^3$
$+ B^2 C r s^2 t^2 + B C^2 r s^2 t + B C D r s^2 + C^2 r s t^3 + B C^2 r s t^2 + C^3 r s t + C^2 D r s + C D r t^3 + B C D r t^2 + C^2 D r t$
$+ C D^2 r + D s^3 t^3 + B D s^3 t^2 + C D s^3 t + D^2 s^3 + B D s^2 t^3 + B^2 D s^2 t^2 + B C D s^2 t + B D^2 s^2 + C D s t^3$
$+ B C D s t^2 + C^2 D s t + C D^2 s + D^2 t^3 + B D^2 t^2 + C D^2 t + D^3$.

We group the monomials $r^is^jt^k$ by total degree and by permutations of the exponent trip $(i,j,k)$:

$=(r^3 + Br^2 + Cr + D)(s^3 + Bs^2 + Cs + D)(t^3 + Bt^2 + Ct + D)$
$= r^3 s^3 t^3$  
$+ B \left( r^3 s^3 t^2 + r^3 s^2 t^3 + r^2 s^3 t^3 \right)$

Newton's formula (p. 6):
$r^3 s^3 t^3 = (rst)^3 = (-d)^3$
$r^3 s^3 t^2 + r^3 s^2 t^3 + r^2 s^3 t^3 =cd^2$
$r^3 s^2 t^2 + r^2 s^3 t^2 + r^2 s^2 t^3 =-bd^2$
$r^2s^2t^2 = (rst)^2 = (-d)^2 = d^2$ 
$r^3 s^3 t + r^3 s t^3 + r s^3 t^3 = (rst)(r^2s^2+r^2t^2+s^2t^2)=(rst)[(rs+rt+st)^2-2rst(r+s+t)]=-dc^2 + 2bd^2$
$r^3 s^2 t + r^3 s t^2 + r^2 s^3 t + r^2 s t^3 + r s^3 t^2 + r s^2 t^3 = bcd-3d^2$
$r^2 s^2 t + r^2 s t^2 + r s^2 t^2 = -cd$
$r^3 s t + r s^3 t + r s t^3 = -b^2d+2cd$
$r^2 s t + r s^2 t + r s t^2 = bd$
$rst = -d$
$r^3 s^3 + r^3 t^3 + s^3 t^3 = c^3-3bcd+3d^2$ 
$r^3 s^2 + r^3 t^2 + r^2 s^3 + r^2 t^3 + s^3 t^2 + s^2 t^3 = -bc^2+2b^2d+cd$
$r^2 s^2 + r^2 t^2 + s^2 t^2 = c^2 - 2bd$
$r^3 s + r^3 t + r s^3 + r t^3 + s^3 t + s t^3 = b^2c - 2c^2 - bd$
$r^2 s + r^2 t + r s^2 + r t^2 + s^2 t + s t^2 = -bc + 3d$
$r s + r t + s t = c$
$r^3 + s^3 + t^3 = -b^3+3bc-3d$
$r^2 + s^2 + t^2 = b^2 - 2c$
$r + s + t = -b$

We substitute the right hand side of Newton's formula to construct a polynomial in terms of $b$,$c$,$d$,$B$,$C$, and $D$:
$g(r)g(s)g(t)$
$=(r^3 + Br^2 + Cr + D)(s^3 + Bs^2 + Cs + D)(t^3 + Bt^2 + Ct + D)$
$= -d^3 + B(cd^2) + B^2(-bd^2) + B^3(d^2) + C(-dc^2 + 2bd^2)+ BC(bcd - 3d^2) + B^2C(-cd)$
$+ C^2(-b^2d + 2cd) + BC^2(bd) + C^3(-d) + D(c^3- 3bcd + 3d^2) + BD(-bc^2 + 2b^2d + cd)$
$+ B^2D(c^2 - 2bd)+ CD(b^2c - 2c^2 - bd)+ BCD(-bc + 3d) + C^2D(c) + D^2(-b^3 + 3bc - 3d)$
$+ BD^2(b^2 - 2c) + CD^2(-b) + D^3$.

Thus, we have re-expressed the condition as $P(b,c,d,B,C,D)=0$:
$g(r)g(s)g(t)$
$=P(b,c,d,B,C,D)$
$= -d^3 + Bcd^2 - B^2bd^2 + B^3d^2 - Cdc^2 + 2Cbd^2 + BCbcd - 3BCd^2 - B^2Ccd - C^2b^2d + 2C^2cd$
$+ BC^2bd - C^3d + Dc^3 - 3Dbcd + 3Dd^2 - BDbc^2 + 2BDb^2d + BDcd + B^2Dc^2 - 2B^2Dbd + CDb^2c$
$- 2CDc^2 - CDbd - BCDbc + 3BCDd+ C^2Dc - D^2b^3 + 3D^2bc - 3D^2d + BD^2b^2 - 2BD^2c - CD^2b$
$+ D^3$.

Notes
- The exercise shows how symmetric functions of the roots (Newton’s identities) let you eliminate the roots and express any symmetric condition in terms of coefficients. This is the classical route (used by Newton) to pass from statements about roots to statements about coefficients.
- The vanishing of $P$ is exactly the algebraic test for a common root.
- Any symmetric polynomial in the roots of an equation can be expressed in terms of the coefficients of that equation.
- Symmetric polynomial in r,s,t means that the expression g(r)g(s)g(t) doesn't change if you permute r,s,t - that is: g(r)g(s)g(t)=g(s)g(r)g(t)=g(t)g(s)g(r).
