Use the Stone-Weierstrass Theorem to show that any continuous function $f \in C([a,b] \times [c,d])$ can be uniformly approximated by functions of the form $F(x,y) = \sum_{i,j=0}^n a_{ij}x^iy^j$.

Let $K = [a,b] \times [c,d]$, which is compact in $\mathbb{R}^2$.

**Step 1: Construct candidate subalgebra**
Let $A = span \{ x^iy^j : i,j \ge 0 \}$.
Then $A \subset C(K)$ since all monomials $x^iy^j$ are continuous on $K$, and finite linear combinations of continuous functions  are continuous. 
Moreover, $A$ is an algebra: 
- It is closed under addition and scalar multiplication by definition. 
- It is closed under multiplication since $(x^i y^j)(x^k y^l) = x^{i+k} y^{j+l} \in A$.

**Step 2: Verify constants**
The constant function $1 \in A$, since $1 = x^0 y^0$. Hence, $A$ contains all constant functions.

**Step 3: Verify point-separating property**
Let $(x_1, y_1)$, $(x_2, y_2) \in K$ with $(x_1, y_1) \ne (x_2, y_2)$.
- If $x_1 \ne x_2$, then the function $f(x,y) = x \in A$ satisfies  $f(x_1, y_1) \ne f(x_2, y_2)$.
- If $x_1 = x_2$ but $y_1 \ne y_2$, then $f(x,y) = y \in A$ separates the points.
Thus, $A$ separates points on $K$.

**Step 4: Apply Stone-Weierstrass Theorem**
The set $A$ is a subalgebra of $C(K)$, contains constants, and separate points.
Therefore, by the Stone-Weierstrass Theorem, $\bar{A}^{\Vert \cdot \Vert_{\infty}} = C(K)$.

**Conclusion**
For every $f \in C([a,b] \times [c,d])$ and every $\epsilon > 0$, there exists a polynomial $F(x,y) = \sum_{i,j=0}^{n} a_{ij}x^iy^j$ s.t. $sup_{(x,y)\in[a,b] \times [c,d]} | f(x,y) - F(x,y)| < \epsilon$. So any continuous function on a rectangle can be uniformly approximated by polynomials in $x$ and $y$.

Notes
- It generalizes polynomial approximation to higher dimensions. Every continuous function $[a,b]$ can be approximated by polynomials (the Weierstrass approximation theorem). This problem shows that: the same idea works in two variables and the approximating functions are polynomials in both $x$ and $y$: $\sum_{i,j} a_{ij}x^i y^j$ so it extends approximation theory from lines to surfaces.
- Instead of constructing approximations explicitly (which gets very hard in higher dimensions), you verify three abstract properties: 1) algebra structure, 2) contains constants , 3) separates points - boom you get density in $C(K)$.
- It justifies using polynomials as universal approximators. This result tells you: Polynomials in $x$ and $y$ are rich enough to approximate any continuous surface on a rectangle.
