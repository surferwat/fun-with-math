 If $C$ is a closed subset of a vector space $X$ show that $C$ is convex if and only if $a, b \in C$ implies that $(a+b)/2 \in C$.

(=>)
Since $C$ is convex,  $a,b \in C \rightarrow \lambda a + (1-\lambda)b \in C$ for all $\lambda \in [0,1]$. 
 $\lambda = \frac{1}{2}$ is in the interval $[0,1]$ so $\frac{1}{2} a + \frac{1}{2}b \in C$.
$\frac{1}{2} a + \frac{1}{2}b  = \frac{(a+b)}{2}$, so $\frac{(a+b)}{2} \in C$.
Thus, $C$ is convex $\rightarrow a,b \in C$ and $\frac{(a+b)}{2} \in C$.
(<=)
WTS: $\forall a,b \in C$, $\forall \lambda \in [0,1]$, $(1-\lambda)a+\lambda b \in C$. 
Let $a,b \in C$.
Then by assumption $\frac{(a+b)}{2} \in C$. Note that $\frac{(a+b)}{2} = (1- \frac{1}{2})a+ \frac{1}{2} b$, a dyadic convex combination.
From this, using repeated midpoint operations, we can recursively construct points of the form: $x_{\lambda} = (1-\lambda)a + \lambda b$, for any dyadic rational $\lambda = \frac{k}{2^n}$ for a fixed $n \in \mathbb{N}$, $k=0,1,...,2^n$.
Since these points are constructed only using midpoint operations and the midpoint of any two points in $C$ is in $C$, it follows that $(1-\lambda)a+\lambda b \in C$ for all dyadic rational $\lambda \in [0,1]$.
The set of dyadic rationals in $[0,1]$ is dense in $[0,1]$, so for any real $\lambda \in [0,1]$, there exists a sequence $\lambda_n \in [0,1] \cap \mathbb{Q}_{dyadic}$ s.t. $\lambda_n \rightarrow \lambda$. 
Let $x_n = (1-\lambda_n)a + \lambda_n b$.
Since each $x_n \in C$ (as each $\lambda_n$ is dyadic) and $\lambda_n \rightarrow \lambda$, then $lim_{n \rightarrow \infty} \, x_n = (1-\lambda)a + \lambda b$.
Since $C$ is closed and all $x_n \in C$, the limits of $x_n$ also lie in $C$.
Therefore, $(1-\lambda)a+\lambda b \in C$ for  $\forall \lambda \in [0,1]$.
