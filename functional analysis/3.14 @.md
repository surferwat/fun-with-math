Let $(X, \Vert \cdot \Vert)$ be a normed space. If $A \subseteq B \subseteq X$ with $A$ dense in $B$ show that $cline(A)=cline(B)$. Deduce that if $A$ is dense in $B$ and $B$ is dense in $X$ then $A$ is dense in $X$ (equivalently that $cline(A) =X$).

$\mathit{Proof}$
WTS: $clin(A) \subseteq clin(B)$ and $clin(A) \supseteq clin(B)$.

Show that $clin(A) \subseteq clin(B)$.
$A \subseteq B \implies Span(A) \subseteq Span(B)$.
Taking closures, we get $\overline{Span(A)} \subseteq \overline{Span(B)} \implies clin(A) \subseteq clin(B)$.

Show that $clin(A) \supseteq clin(B)$.
Since $B \subseteq X$, $\exists x \in X$ s.t. $x \in Span(B)$.
Let $x = \sum_{i=1}^{n} \alpha_i b_i \in Span(B)$ s.t. $i \in \mathbb{N}$, $\alpha \in \mathbb{R}$.
Since $A$ is dense in $B$, for each $b_i \in B$, there exists a sequence $(a_{j}^{k})_{k \in \mathbb{N}} \subseteq A$ s.t. $a_{i}^{k} \to b_i$ as $k \to \infty$.
Define $x_k := \sum_{i=1}^{n} \alpha_ia_{i}^{k} \in Span(A)$.
Then $\Vert x_k - x \Vert = \Vert \sum_{i=1}^{n} \alpha_i(a_{i}^{k} - b_i) \Vert \le \sum_{i=1}^{n} |\alpha_i|\Vert a_{i}^{k} - b_i \Vert \to 0$ as $k \to \infty$.
So, $x_k \to x$ in norm, and $x_k \in Span(A) \implies x \in Span(A) \implies x \in \overline{Span(A)}$
So, for every $x \in Span(B)$ is in $\overline{Span(A)}$.
Thus, $Span(B) \subseteq Span(A) \implies \overline{Span(B)} \subseteq \overline{Span(A)} \implies clin(B) \subseteq clin(A)$.

Thus, $clin(A) \subseteq clin(B)$ and $clin(B) \subseteq clin(A)$, so $clin(A) = clin(B)$. $\blacksquare$

$\mathit{Proof}$
Deduce that $A$ is dense in $X$.
$A$ is dense in $B$, so for any $\epsilon > 0$, there exists $a \in A$ s.t. $\Vert b - a \Vert < \epsilon$.
$B$ is dense in $X$, so for any $\epsilon > 0$, there exists $b \in B$ s.t. $\Vert x - b \Vert < \epsilon$.

Fix arbitrarily $x \in X$.
Let $\Vert b - a \Vert < \frac{\epsilon}{2}$.
Let $\Vert x - b \Vert < \frac{\epsilon}{2}$.
Then for any $\epsilon > 0$, there exists $a \in A$ and $b \in B$ s.t. $\Vert x - b \Vert + \Vert b - a \Vert < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon$.
Using Minkowski's inequality, $\Vert x-a \Vert = \Vert (x-b) + (b-a) \Vert \le \Vert x - b \Vert + \Vert b - a \Vert < \epsilon$.
Thus, $\Vert x - a \Vert < \epsilon$, so $A$ is dense in $X$. $\blacksquare$

Notes
- $cline(A)=\overline{Span(A)}$, which is the closure of $Span(A)$ and is the set of all elements of $X$ that can be approximated arbitrarily closely by finite linear combinations of elements of $A$.
- $cline(B)=\overline{Span(B)}$, which is the closure of $Span(B)$ and is the set of all elements of $X$ that can be approximated arbitrarily closely by finite linear combinations of elements of $B$.
- This exercise shows that density is transitive.
- In analysis, we often approximate functions or elements using simpler subsets. Understanding that you can "chain" these approximations and still get close to the whole space is essential.
- This result lets you:
	- Build dense subsets of spaces **incrementally**.
	- Start with a small, manageable set $A$,
	- Approximate all of $B$,
	- Then all of $X$.
- For example, in the study of:
	- **Hilbert spaces**: you often work with a countable orthonormal set that's dense in the space.
	- **Banach spaces**: you often want to know that certain subspaces are dense for practical computations.
	- **Distribution theory**: test functions are dense in $L^p$ spaces in weak topology — built through layered approximations.
