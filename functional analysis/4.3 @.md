Show, using Lemma 4.6, that $\mathbb{K}^n$ is complete.

A metric space in which any Cauchy sequence converges is called complete.
Cauchy means for every $\epsilon > 0$ there exists an $N$ s.t. $d(x_n, x_m) < \epsilon$ for all $n,m \ge N$.
A normed space $(X, \Vert \cdot \Vert)$ is complete  if every Cauchy sequence in $X$ converges in $X$ (to a limit that lies in $X$). 

It is a standard result that: $\mathbb{R}$ is complete with respect to the absolute value norm and $\mathbb{C}$ is complete with respect to the modulus norm.
Thus, $(\mathbb{K}, | \cdot |)$ is complete.

$\mathit{Proof}$
We write $\mathbb{K}^n = \mathbb{K}_1$ X $\mathbb{K}_2$ X ... X $\mathbb{K}_n$, where each $\mathbb{K}_i = \mathbb{K}$ equipped with the usual norm $| \cdot |$.
Thus, each $(\mathbb{K}_i, | \cdot |)$ is complete.

Lemma 4.6 states if $(X, \Vert \cdot \Vert_X)$ and $(\Vert Y, \Vert \cdot \Vert_Y)$ are complete, then $X$ x $Y$ is complete for the norm $\Vert(x,y)\Vert_1 := \Vert x \Vert_X + \Vert y \Vert_Y$ (the standard norm on $X$ x $Y$) and also for the (equivalent) norm $\Vert \cdot \Vert_2$ defined by $\Vert (x,y) \Vert_2 := (\Vert x \Vert_X^2 + \Vert y \Vert_Y^2)^{(1/2)}$.
We apply this lemma repeatedly: 
	Since $\mathbb{K}_1$ and $\mathbb{K}_2$ are complete, $\mathbb{K}_1$ x $\mathbb{K}_2$ is complete.
	Since $\mathbb{K}_1$ x $\mathbb{K}_2$ and $\mathbb{K}_3$ are complete, $(\mathbb{K}_1$ x $\mathbb{K}_2)$ x $\mathbb{K}_3$ is complete.
	Continue inductively to show $\mathbb{K}_1$ x ... x $\mathbb{K}_n$ is complete.

Thus, $\mathbb{K}^n$ is complete. $\blacksquare$

Notes
- This problem shows that the familiar space $\mathbb{K}^n$ is a Banach space, making it the foundational example that explains why finite-dimensional analysis is stable, well-behaved, and fundamentally different from infinite-dimensional analysis.
