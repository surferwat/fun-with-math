Show that if $X$ is a normed space and $U$ is a closed linear subspace of $U$, then $\Vert [x] \Vert_{X/U} = inf_{u \in U} \Vert x + u \Vert_{X}$ defines a norm on the quotient space $X/U$ introduced in Exercise 1.6. Show that if $X$ is complete, then $X/U$ is complete with this norm. (Use Lemma $4.14$ for the completeness.)

**Step 1: definiteness**
WTS $\Vert [x] \Vert = 0 \iff [x] = [0]$.
If $x \in U$, then choosing $u = -x$, $\Vert [x] \Vert \le \Vert x - x \Vert = 0$, so $\Vert [x] \Vert = 0$. 
Conversely, suppose $\Vert [x] \Vert = 0$. Then there exists a sequence $(u_n) \subset U$ s.t. $\Vert x + u_n \Vert \rightarrow 0$.
Hence $x + u_n \rightarrow 0$, so $x = -lim\ u_n$.
Since $U$ is closed, the limit belongs to $U$, hence $x \in U$, so $[x] = [0]$.

**Step 2: homogeneity**
WTS $\Vert \lambda [x] \Vert = |\lambda|\Vert[x]\Vert$.
For $\lambda \in \mathbb{F}$, $\Vert \lambda [x] \Vert = inf_{u \in U} \Vert \lambda x + u \Vert = inf_{v \in U} \Vert \lambda (x + v) \Vert = |\lambda| inf_{v \in U} \Vert x + v \Vert = | \lambda | \Vert [x] \Vert$.

**Step 3: triangle inequality**
WTS $\Vert [x+y] \Vert \le \Vert [x] \Vert + \Vert [y] \Vert$
For any $u_1, u_2 \in U$, $\Vert x + y + (u_1 + u_2) \Vert \le \Vert x + u_1 \Vert + \Vert y + u_2 \Vert$. 
By definition,  $\Vert [x+y] \Vert = inf_{u \in U} \Vert x + y + u \Vert$. 
Thus, $\Vert [x+y] \Vert = inf_{u \in U} \Vert x + y + u \Vert \le \Vert x + y + (u_1 + u_2) \Vert \le \Vert x + u_1 \Vert + \Vert y + u_2 \Vert$
Since inequality holds for all $u_1, u_2 \in U$, it also holds for the smallest possible values of the right-hand side $\Vert [ x + y] \Vert \le inf_{u_1 \in U} \Vert x + u_1 \Vert + inf_{u_2 \in U} \Vert y + u_2 \Vert$.
But these infima are exactly the quotient norms, $\Vert [x+y] \Vert \le \Vert [x] \Vert + \Vert [y] \Vert$.

Thus, $\Vert \cdot \Vert_{X/U}$ is a norm.

**Step 4: Completeness of $X / U$**
Assume now that $X$ is complete.
Let $([x_n])$ be a Cauchy sequence in $X/U$.
By definition, for every $\epsilon > 0$, there exists $N$ s.t. $\Vert [x_n] - [x_m] \Vert = \Vert[x_n -x_m] \Vert < \epsilon$ for $n,m \ge N$.
By definition of the quotient norm, for each pair $n, m$ choose $u_{n,m} \in U$ s.t. $\Vert (x_n - x_m) + u_{n,m} \Vert < \epsilon$.
Using $Lemma \, 4.14$ (the standard lifting lemma for quotient spaces), we can select representatives $y_n \in [x_n]$ s.t. $(y_n)$ is a Cauchy sequence in $X$.
Since $X$ is complete, there exists $y \in X$ with $y_n \rightarrow y$. 
Then $\Vert [x_n] - [y] \Vert = \Vert [y_n - y] \Vert \rightarrow 0$, so $[x_n] \rightarrow [y] \in X/U$.
Thus, every Cauchy sequence in $X/U$ converges.

**Conclusion**
The formula $\Vert [x] \Vert_{X/U} = inf_{u \in U} \Vert x + u \Vert$ defines a norm on $X/U$. 
If $X$ is complete and $U$ is closed, then $X/U$ is complete with respect to this norm.

Notes:
- The quotient space X/U is the set of all equivalence classes $[x] = x + U := { x+u : u \in U }$.
- This is the standard quotient norm construction in functional analysis.
