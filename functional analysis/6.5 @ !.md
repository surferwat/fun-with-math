Define a sequence of polynomials $p_n:[-1,1] \to \mathbb{R}$ iteratively, by setting $p_0(x) = 0$ and $p_{n+1}(x) = \frac{1}{2} x^2 + p_n(x) - \frac{1}{2}p_n(x)^2$. Using the result of the previous exercise show that $p_n(x) \to |x|$ uniformly on $[-1,1]$ as $n \to \infty$. (First consider the map $f:[-1,1] \to \mathbb{R}$ given by $p \mapsto \frac{1}{2} x^2 + p - \frac{1}{2}p^2$. This gives another way to prove Lemma 6.7.) (Pryce 1973).

**Step 1: Fixed points of the map**
Solve $p=f_x(p):$
$p = \frac{1}{2}x^2 + p - \frac{1}{2}p^2$
$0=\frac{1}{2}x^2 - \frac{1}{2}p^2$
$p^2 = x^2$
$p = \pm |x|$

**Step 2: Monotonicity and bounds**
First observe that for $x \in [-1,1]$, $p_{n+1}(x) - p_n(x) =\frac{1}{2}(x^2 - p_n(x)^2) =\frac{1}{2}(|x| - p_n(x))(|x| + p_n(x))$.
We prove by induction that $0 \le p_n(x) \le |x|$ for all $n$.
Base case:
$p_0(x) = 0$.
Inductive step:
Assume $0 \le p_n \le |x|$. Then $p_{n+1} = p_n + \frac{1}{2}(x^2 - p_n^2) \ge p_n \ge 0$ and $p_{n+1} - |x| = p_n - |x| + \frac{1}{2}(x^2-p_n^2) = (p_n - |x|) (1-\frac{1}{2}(p_n + |x|)) \ge 0$ since $p_n + |x| \le 2$.
Thus, $0 \le p_n(x) \le p_{n+1}(x) \le |x|$.
Hence for every $x, p_n(x)$ is increasing and bounded above by $|x|$.
Therefore $p_n(x) \to L(x)$ for some $L(x) \le |x|$.

**Step 3: Identify the limit**
Passing to the limit in $p_{n+1} =f_x(p_n)$ gives $L=f_x(L)$.
Thus $L$ must be a fixed point of $f_x$ so $L = \pm |x|$.
But since $p_n(x) \ge 0$ the limit must be $L(x) = |x|$.
Hence $p_n(x) \to |x|$ pointwise on $[-1,1]$.

**Step 4: Uniform convergence**
Let $e_n(x) = |x| - p_n(x) \ge 0$.
Using the recurrence, $e_{n+1} = |x| - p_{n+1} = |x| - p_n - \frac{1}{2}(x^2-p_n^2)$.
Since $x^2 = |x|^2$, $e_{n+1} = e_n - \frac{1}{2}(|x|^2 - p_n^2) = e_n - \frac{1}{2}(|x|-p_n)(|x|-p_n)=e_n(1-\frac{1}{2}(|x|+p_n))$.
Because $0 \le p_n \le |x| \le 1$, $0 \le 1 - \frac{1}{2}(|x| +p_n) \le \frac{1}{2}$.
Thus $0 \le e_{n+1}(x) \le \frac{1}{2}e_n(x)$.
Iterating, $0 \le e_n(x) \le 2^{-n}e_0(x) = 2^{-n}|x| \le 2^{-n}$.
Therefore $sup_{x\in[-1,1]} |p_n(x) - |x|| = sup_{x\in[-1,1]} e_n(x) \le 2^{-n} \to 0$.

**Conclusion**
$p_n(x) \to |x|$ uniformly on $[-1,1]$.

Notes
- The sequence $p_n(x)$ consists entirely of polynomials: $p_0(x) = 0$, $p_{n+1}(x) = \frac{1}{2}x^2+p_n(x) - \frac{1}{2}p_n(x)^2$. Each step uses algebraic operations on polynomials, so every $p_n$ is a polynomial. The result shows $p_n(x) \to |x|$ uniformly on $[-1,1]$. Thus, we have constructed a sequence of polynomials that uniformly approximates the non-smooth function $|x|$.
- This exercise is interesting because it gives a very simple recursive construction of polynomial approximations to $|x|$, which: avoids heavy approximation theory, uses only elementary inequalities, still proves uniform convergence. It is a beautiful example of analysis emerging from a clever algebraic iteration.
- In short, the problem illustrates three key ideas: polynomial approximation of continuous functions, fixed point iteration methods, uniform convergence in function spaces.
