Show that if $m = max_{j=1,...,n} | x_j |$, then for any $p \in [1,\infty)$, $m^p \le \sum_{j=1}^n | x_j |^p \le nm^p$ and deduce that for any $x \in \mathbb{K}^n$, $\Vert x \Vert_{l^p} \rightarrow \Vert x \Vert_{l^\infty}$ as $p \rightarrow \infty$.

Let $x_1, x_2, ..., x_n \in X$.
Since $m = max_{j=1,...,n} | x_j|$, there exists some index $i \in \{1, ..., n\}$ s.t. $| x_i | = m \rightarrow | x_i |^p = m^p$.
Since $|x_j| \ge 0$ and $p > 0$, the sum must satisfy: $m^p = |x_i|^p \le \sum_{j=1}^{n} | x_j |^p$.
For all $j=1,...,n$, we have $| x_j | \le m$, so $|x_j|^p \le m^p$ since $p > 0$. 
Then $|x_1|^p \le m^p$, $|x_2|^p \le m^p$, ..., $|x_n|^p \le m^p$.
Summing these inequalities, we get $|x_1|^p + |x_2|^p + ... + |x_n|^p \le m^p + m^p + ... + m^p \implies \sum_{j=1}^{n} |x_j|^p \le nm^p$.
Therefore, $m^p \le \sum_{j=1}^n | x_j |^p \le nm^p$.

$(m^p)^{\frac{1}{p}} \le  (\sum_{j=1}^n | x_j |^p)^{\frac{1}{p}} \le (nm^p)^\frac{1}{p} \implies m \le  (\sum_{j=1}^n | x_j |^p)^{\frac{1}{p}} \le n^{\frac{1}{p}}m$.
As $p \rightarrow \infty$, we have $n^\frac{1}{p} \rightarrow 1$, so by the squeeze theorem, $\Vert x \Vert_{l^p} \to m = \Vert x \Vert_{l^{\infty}}$.
