 If $A$ and $B$ are subsets of a vector space, then we can define $A + B := {a+b : a \in A, b\in B}$. Show that if $A$ and $B$ are both convex, then so is $A+B$.
 
$\lambda(a_1+b_1) + (1-\lambda)(a_2+b_2)= \lambda(a_1) + \lambda(b_1) + (1-\lambda)a_2 + (1-\lambda)b_2$.
Rearranging terms, we have $\lambda(a_1) + (1-\lambda)a_2 + \lambda(b_1) + (1-\lambda)b_2$. 
Since A and B are convex, $\lambda(a_1) + (1-\lambda)a_2 \in A$ and $\lambda(b_1) + (1-\lambda)b_2 \in B$.
By definition of A+B, we have $\lambda(a_1) + (1-\lambda)a_2+ \lambda(b_1) + (1-\lambda)b_2 \in A+B$.
Thus, $\lambda(a_1+b_1) + (1-\lambda)(a_2+b_2)\in A+B \rightarrow A+B$ is convex.
