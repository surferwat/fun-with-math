Show that if $K$ is a non-empty open subset of $\mathbb{R}^n$ that is $(i)$ convex, $(ii)$ symmetric ($x \in K$ implies that $-x \in K$), and $(iii)$ bounded, then $N(x) := inf(M > 0 : M^{-1} x \in K$) defines a norm on $\mathbb{R}^n$ ($K$ is the unit ball for $N$).

Since $K$ is open and nonempty, there exists $\epsilon > 0$ s.t. $B(0,\epsilon) \subset K$. Hence $0 \in K$. Because $K$ is bounded, there exists $R > 0$ s.t. $K \subset B(0,R)$. Because $K$ is symmetric, $x \in K \iff -x \in K$. 

**Step 1: $N(x)$ is finite and nonnegative**
Since we don't yet know anything about $N$, the only concrete set we can use is the Euclidean ball $B(0, \epsilon) = \{ z : \Vert z \Vert < \epsilon \} \subset K$. 
By definition of the Euclidean ball, this means $\Vert \frac{x}{M} \Vert < \epsilon \Rightarrow \frac{\Vert x \Vert}{M} < \epsilon \Rightarrow M > \frac{\Vert x \Vert}{\epsilon}$.
So, for any $x \in R^n$ since $B(0, \epsilon) \subset K$, $\frac{x}{M} \in K$ whenever $M > \frac{\Vert x \Vert}{\epsilon}$. 
Thus, the set defining $N(x)$ is nonempty, so $N(x) < \infty$. 
Clearly $N(x) \ge 0$, and $N(0) = 0$.

**Step 2: $N(x) = 0 \iff x = 0$**
If $x = 0$, then $M^{-1}x = 0 \in K$ for all $M > 0$, so $N(0) = 0$. 
If $x \ne 0$: since $K \subset B(0,R)$, $M^{-1}x \in K \Rightarrow \Vert x \Vert \le MR$. Hence $M \ge \frac{\Vert x \Vert}{R}$ so $N(x) \ge \frac{\Vert x \Vert}{R} > 0$. Thus, $N(x) = 0 \iff x = 0$.

**Step 3: Absolute homogeneity　（key use of symmetry)**　
Let $\lambda \in \mathbb{R}$, $\lambda \ne 0$. 
$M^{-1}(\lambda x) = \frac{\lambda}{M} x = \frac{sgn(\lambda)}{M / | \lambda |} x$.
Since positivity: $M > 0 \Rightarrow \frac{M}{\lambda} > 0$ and since symmetry of $K$: if $z \in K$, then $-z \in K$ so the factor $sgn(\lambda) \in {\pm 1}$ does not affect membership in $K$, allowing us to drop it and giving us:e $M^{-1}(\lambda x) \in K \iff (M / | \lambda |)^{-1} x \in K$.
Thus, $N(\lambda x) = inf\{M > 0 : M^{-1}(\lambda x) \in K \}= inf\{ M > 0 : (\frac{M}{|\lambda|})^{-1}x \in K \}$.
Define a new variable $t := \frac{M}{|\lambda|}$. Then $M = |\lambda|t$, $M > 0 \iff t > 0$, $(M/|\lambda|)^{-1}x = t^{-1}x$. So the set becomes $\{M = | \lambda | t : t > 0$ and $t^-1 x \in K \}$. By definition, $inf\{M : M^{-1}(\lambda x) \in K \} = inf \{ | \lambda | t : t > 0, t^{-1} x \in K \}$. Factor out $|\lambda|$ (constant with respect to $t$): $inf \{ |\lambda| t : t > 0, t^{-1} x \in K \} = |\lambda| inf \{t > 0 : t^{-1} x \in K \}$.
Thus, $|\lambda|N(x)= |\lambda| inf \{t > 0 : t^{-1} x \in K \} = |\lambda|N(x)$.
For $\lambda = 0$, this also holds since $N(0)=0$. 
Thus $N(\lambda x) = |\lambda|N(x)$.

**Step 4: Triangle inequality (key use of convexity)**
Let $x,y \in \mathbb{R}^n$ and let $\epsilon > 0$. Choose $M_1, M_2$ s.t. $M_1^{-1}x \in K$, $M_2^{-1} y \in K$, with $M_1 < N(x) + \epsilon$, $M_2 < N(y) + \epsilon$. By convexity of $K$, $\frac{M_1}{M_1 + M_2}(M_1^{-1}x) + \frac{M_2}{M_1+M_2}(M_2^{-1}y) \in K$. 
This equals $(M_1+M_2)^{-1}(x+y)\in K$. 
Hence $N(x+y) \le M_1 + M_2 < N(x) + N(y) + 2\epsilon$.
Letting $\epsilon \to 0$ gives $N(x+y) \le N(x) + N(y)$.

**Conclusion**
The function $N$ satisfies:
1. $N(x) \ge 0 \iff x = 0$,
2. $N(\lambda x) = | \lambda | N(x)$,
3. $N(x+y) \le N(x) + N(y)$,
so $N$ is a norm on $\mathbb{R^n}$ and $K$ is its unit ball. This construction is known as the **Minkowski functional** associated with $K$.

Notes
- **$K$ is the unit ball of $N$.** We claim: $K = \{ x \in \mathbb{R}^n : N(x) < 1 \}$. If $x \in K$, then $1^{-1}x \in K$ so $N(x) \le 1$. Since $K$ is open, in fact $N(x) < 1$.  If $N(x) < 1$, then there exists $M < 1$ with $M^{-1}x \in K$. By convexity and symmetry, this implies $x \in K$. Thus $K$ is exactly the open unit ball of $N$.
