Show that the set $b := \{ x \in l^{\infty} : x_j = 0 \, \text{or} \, 1$ for each $j \in \mathbb{N} \}$ is uncountable.

AFSOC that $b$ is countable.
Then we could list all its elements in a sequence $x^{(1)}$, $x^{(2)}$, $x^{(3)}$ ... $x^{(n)}$ where each $x^{(i)} = \{ x_1^{(i)}, x_2^{(i)}, x_3^{(i)}, ... , x_m^{(i)} \} \in b$ with each $x_i^{(i)} = 1$ and $x_j^{(i)} = 0$ s.t. $i \ne j$.   

| j   | x        |
| --- | -------- |
| 0   | 10000... |
| 1   | 01000... |
| 2   | 00100... |
| n   | 0 ... 01 |
Now we construct sequence $y^{(n+1)}$ s.t. each position $j$ corresponds to the $i$th position of $x_{i}$.
Then $y^{(n+1)} \in l^{\infty}$ because it is a bounded sequence of $0$'s and $1$'s and $y^{(n+1)} \in b$ since  $y_{j}^{(n+1)} = 0$ or $1$.
But $y^{(n+1)} \ne x^{(i)}$ since it shares the same value of $x^{(i)}$ in no more than one position.
Thus, we have constructed a new sequence  $y^{(n+1)}$ that is not in the list, so we have arrived at a contradiction.
Thus, $b$ is uncountable.

Notes:
- The set $b=\{x \in l^{\infty} : x_j=0$ or $1 \} is a very "simple" subset of $l^{\infty}$ : it only allows sequences made up of $0$’s and $1$’s.
- Yet this subset is uncountable, showing that even very "sparse" parts of infinite-dimensional spaces can be large in terms of cardinality.
- This is a concrete application of Cantor’s diagonalization — a foundational idea in modern mathematics.
- $l^{\infty}$ is a Banach space — an infinite-dimensional vector space with a norm. Understanding the structure of subsets like $b$ helps grasp the "size" and complexity of infinite-dimensional spaces.
