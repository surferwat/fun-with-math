Prove Dini's Theorem: suppose that $(f_n) \in C([a,b]; \mathbb{R})$ is an increasing sequence $(f_{n+1}(x) \ge f_n(x))$ that converges pointwise to some $f \in C([a,b]; \mathbb{R})$. Show that $f_n$ converges uniformly to $f$. (For each $\epsilon > 0$ consider the sets $E_n := \{x \in [a,b] : f(x) - f_n(x) < \epsilon \}$ and use the compactness of $[a,b]$.)

**Step 1: Define open sets**
For $\epsilon > 0$ define $E_n := \{ x \in [a,b] : f(x) - f_n(x) < \epsilon \}$.
Since $f - f_n$ is continuous, $E_n = (f - f_n)^{-1}((-\infty, \epsilon))$ is open in $[a,b]$.

**Step 2: Nested property**
Because $f_{n+1}(x) \ge f_n(x)$, $f(x) - f_{n+1}(x) \le f(x) - f_n(x)$.
Thus, $E_1 \subseteq E_2 \subseteq E_3 \subseteq ...$.

**Step 3: Covering property**
Since $f_n(x) \to f(x)$, we have $f(x) - f_n(x) \to 0$.
Therefore for every $x \in [a,b]$ there exists $n$ such that $f(x) - f_n(x) < \epsilon$, so $\bigcup_{n=1}^{\infty} = [a,b]$.

**Step 4: Use compactness**
The sets $E_n$ form an open cover of the compact set $[a,b]$.
Thus, there exist indices $n_1, ..., n_k$ s.t. $[a,b] \subseteq E_{n_1} \cup$ .. $\cup$ $E_{n_k}$.
Let $N= max \{ n_1, ..., n_k \}$.
Since the sets are nested $E_{n_i} \subseteq E_N$, so $[a,b] \subseteq E_N$.
Thus for all $x \in [a,b]$, $f(x) - f_N(x) < \epsilon$.

**Step 5: Uniform bound**
For $n \ge N$, $0 \le f(x) - f_n(x) \le f(x) - f_N(x) < \epsilon$ $\forall x \in [a,b]$.
Hence $sup_{x\in[a,b]} | f(x) - f_n(x) | < \epsilon$,  $(n \ge N)$. 

**Conclusion**
Since for every $\epsilon > 0$ there exists $N$ s.t. $sup_{x \in [a,b]} | f(x) - f_n(x) | < \epsilon$ $(n \ge N)$, the convergence $f_n \to f$ is uniform on $[a,b]$. 

Notes
- Pointwise convergence: $f_n(x) \to f(x)$ for each fixed $x$. This is a "local" condition: for each point, eventually the sequence gets close. But the speed of convergence can vary with $x$, so pointwise convergence does not guarantee ncie global behavior. Uniform convergence: $f_n \to f$ uniformly if there exists a single $N$ that works for all $x$ at once. Uniform convergence is crucial because it preserves continuity, integrability, and differentiability under the limit. Without uniform convergence, the limit of continuous functions might fail to be continuous. Dini's Theorem is significant because it gives a sufficient condition (monotone sequences + compact domain + continuous limit) for pointwise convergence to automatically be uniform.
- Uniform convergence guarantees that limits of approximations preserve continuity when you have monotone sequences of functions.
