Show that the conclusion of the Contraction Mapping Theorem (Theorem 4.15) need not hold if $\Vert f(x) - f(y) \Vert_X < \Vert x - y \Vert_X$, $x,y \in K$, but that the result does still hold under this weakened condition if $K$ is compact.

The usual Contraction Mapping Theorem requires a uniform constant $0 < \kappa < 1$ s.t. $\Vert f(x) - f(y) \Vert \le \kappa \Vert x - y \Vert$ $\forall x,y \in K$. The weakened hypothesis only assumes $\Vert f(x) - f(y) \Vert < \Vert x - y \Vert$ $\forall x \ne y$, with no uniform $\kappa < 1$.

**Counterexample (non-compact K)**
Let $X = \mathbb{R}$, $K = \mathbb{R}$, $f(x) = x + e^{-x}$.

**Step 1: Strict inequality holds**
By the Mean Value Theorem, $\frac{f(x) - f(y)}{x-y}=f'(\varepsilon)$ for some $\varepsilon$ between $x,y$.
Here $f'(x) = 1 - e^{-x} \in (0,1)$ $\forall x \in \mathbb{R}$.
Hence for all $x \ne y$, $| f(x) - f(y) | < | x - y |$.

**Step 2: No fixed point exists.**
A fixed point would satisfy $x = f(x) = x + e^{-x}$, which implies $e^{-x} = 0$, impossible.
Thus $f$ has no fixed point, even though the strict inequality holds.
So the conclusion of the Contraction Mapping Theorem fails when $K$ is not compact.

**The result does hold if $K$ is compact**
Assume now: $K \subset X$ is compact, $f : K \rightarrow K$, $\Vert f(x) - f(y) \Vert < \Vert x - y \Vert$ for all $x \ne y$.
We show $f$ has a unique fixed point.

**Step 1: Construct an iterative sequence**
Pick any $x_0 \in K$ and define $x_{n+1} = f(x_n)$.
If $x_n = x_{n+1}$ for some $n$, we are done. 
Otherwise, $\Vert x_{n+1} - x_{n+2} \Vert < \Vert x_n - x_{n+1} \Vert$, so the sequence  $d_n := \Vert x_{n+1} - x_n \Vert$ is strictly decreasing and bounded below by $0$. Hence $d_n \rightarrow d \ge 0$.

**Step 2: Use compactness**
Since $\Vert f(x) - f(y) \Vert \le \Vert x - y \Vert$, $f$ is $1-Lipschitz$ hence continuous.
Since $K$ is compact, $(x_n)$ has a convergent subsequence: $x_{n_k} \rightarrow x^* \in K$.
Continuity of $f$ gives $x_{n_k+1} = f(x_{n_k}) \rightarrow f(x^*)$.
Hence, $\Vert x_{n_k+1} - x_{n_k} \Vert \Vert f(x^*) -x^* \Vert = d$, and taking the limits gives $\Vert f(x^*) - x^* \Vert = d$. 
Assume $d > 0$, applying the strict inequality to $x^*$ and $f(x^*)$ yields $\Vert f(x^*) - f(f(x^*)) \Vert < \Vert x^* - f(x^*) \Vert = d$.
But the left-hand side is the limit of $\Vert x_{n_k+2} - x_{n_k+1} \Vert$ which must also converge to $d$ since the full sequence $d_n \rightarrow d$, contradicting the limit behavior.
Hence $d=0$ and $f(x^*) = x^*$.

**Step 3: Uniqueness**
If $x^* \ne y^*$ were two fixed points $\Vert x^* - y^* \Vert = \Vert f(x^*) - f(y^*) \Vert < \Vert x^* - y^* \Vert$, a contradiction.
So, the fixed point is unique.

Thus, the strict inequality $\Vert f(x) - f(y) \Vert < \Vert x - y \Vert$ does not guarantee a fixed point on non-compact sets. If $K$ is compact, the same inequality does imply existence and uniqueness of a fixed point. This result is often referred to as Edelstein's Fixed Point Theorem, and Robinson's exercise is guiding you toward exactly this distinction.

Notes:
- The usual Contraction Mapping Theorem assumes a uniform contraction (since a single constant $\kappa$, applies for all $x,y \in K$). This problem asks: What if we only know distances strictly decrease, but not at a uniform rate?  The counterexample shows that strict decrease alone is not enough on large (non-compact) sets. So the uniform constant $\kappa < 1$ is not a technical convenience - it prevents the contraction from "flattening out at infinity" (the amount of contraction goes to zero as $x$ gets large).
- The problem shows that if you drop uniformity, you must replace it with compactness and if you drop both, the theorem fails.
