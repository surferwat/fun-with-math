Show that if $x \in l^1$, then $\Vert x\Vert_{l^\infty} = lim_{p \to \infty} \Vert x\Vert_{l^p}$. (Show that for every $\epsilon > 0$ there exists $N$ such that $\Vert x \Vert_{l^p} - \epsilon \le \Vert(x_1, ..., x_n)\Vert_{l^p} \le \Vert x \Vert_{l^p}$ for all $n \ge N$; treat $p \in [1, \infty)$ together using the result of Lemma 3.10, and then $p = \infty$ separately. To finish the proof use the result of Exercise 3.5)

WTS: for every $\epsilon > 0$ there exists $N$ such that $\Vert x \Vert_{l^p} - \epsilon \le \Vert (x_1, ..., x_n) \Vert_{l^p} \le \Vert x \Vert_{l^p}$.
$\Vert x \Vert_{l^1} = \sum_{j=1}^{\infty} | x_j |$.
$\Vert x \Vert_{l^p} = (\sum_{j=1}^{\infty} | x_j |^{p})^{1/p}$.
Fix $\epsilon > 0$.
There exists an $N$ s.t. for all $n \ge N$, $\sum_{j=n+1}^{\infty} | x_j | \le \epsilon$.
Lemma 3.10 tells us $l^1 \subset l^p$ and $\Vert x \Vert_{l^p} \le \Vert x \Vert_{l^1}$ where $1 \le p \le \infty$, so  $(\sum_{j=n+1}^{\infty} | x_j |^p)^{1/p}  \le \sum_{j=n+1}^{\infty} | x_j | \le \epsilon$.
Using Minkowski's inequality, Lemma 3.9, we have $(\sum_{j=1}^{\infty} | x_j |^p)^{1/p} = (\sum_{j=1}^{n} | x_j |^p + \sum_{j=n+1}^{\infty} | x_j |^p)^{1/p} \le (\sum_{j=1}^{n} | x_j |^p)^{1/p} + (\sum_{j=n+1}^{\infty} | x_j |^p)^{1/p} \le (\sum_{j=1}^{n} | x_j |^p)^{1/p} + \epsilon$.
So, $(\sum_{j=1}^{\infty} | x_j |^p)^{1/p} \le (\sum_{j=1}^{n} | x_j |^p)^{1/p} + \epsilon$.
Then, $(\sum_{j=1}^{\infty} | x_j |^p)^{1/p} - \epsilon \le (\sum_{j=1}^{n} | x_j |^p)^{1/p} \le (\sum_{j=1}^{\infty} | x_j |^p)^{1/p}$.
Thus,  $\Vert x \Vert_{l^p} - \epsilon \le \Vert (x_1,...,x_n)\Vert_{l^p} \le \Vert x \Vert_{l^p}$. [1]

WTS: for every $\epsilon > 0$ there exists $N'$ such that $\Vert x \Vert_{l^\infty} - \epsilon \le \Vert (x_1, ..., x_n) \Vert_{l^\infty} \le \Vert x \Vert_{l^\infty}$.
$\Vert x \Vert_{l^\infty} = sup_{j \in \mathbb{N}} | x_j |$.
$\Vert (x_1,...,x_n) \Vert_{l^\infty} = max_{1 \le j \le n} | x_j |$.
Fix $\epsilon > 0$.
By the definition of supremum, there exists some $N'$ s.t. $\Vert x \Vert_{l^\infty} - \epsilon \le | x_{N'} |$.
Then for all $n \ge N'$, we have $\Vert x \Vert_{l^\infty} - \epsilon \le | x_{N'}| \le max_{j=1,...,n} | x_j | \le sup_{j \in \mathbb{N}} | x_j |$.
Thus, $\Vert x \Vert_{l^\infty} - \epsilon \le \Vert (x_1,...,x_n) \Vert_{l^{\infty}} \le \Vert x \Vert_{l^\infty}$. [2]

Fix $n \ge max(N,N')$.
Let $p \in [1,\infty)$.
From Exercise 3.5, we know that for any finite dimensional $x \in \mathbb{K}^n$, $\Vert x \Vert_{l^p} \rightarrow \Vert x \Vert_{l^\infty}$ as $p \rightarrow \infty$.
Taking the limit of [1] we have $lim_{p \to \infty} \Vert x \Vert_{l^p} - \epsilon \le lim_{p \to \infty} \Vert (x_1,...,x_n) \Vert_{l^p} \le lim_{p \to \infty} \Vert x \Vert_{l^p} \implies lim_{p \to \infty} \Vert x \Vert_{l^p} - \epsilon \le \Vert (x_1,...,x_n) \Vert_{l^\infty} \le lim_{p \to \infty} \Vert x \Vert_{l^p}$.
Combining with [2], we have $lim_{p \to \infty} \Vert x \Vert_{l^p} - \epsilon \le \Vert (x_1,...,x_n) \Vert_{l^\infty} \le \Vert x \Vert_{l^\infty} \implies lim_{p \to \infty} \Vert x \Vert_{l^p} \le \Vert x \Vert_{l^\infty} + \epsilon$ and $\Vert x \Vert_{l^\infty} - \epsilon \le \Vert (x_1,...,x_n) \Vert_{l^\infty} \le lim_{p \to \infty} \Vert x \Vert_{l^p} \implies \Vert x \Vert_{l^\infty} - \epsilon \le lim_{p \to \infty} \Vert x \Vert_{l^p}$.
Thus, $\Vert x \Vert_{l^\infty} - \epsilon \le lim_{p \to \infty} \Vert x \Vert_{l^p} \le \Vert x \Vert_{l^\infty} + \epsilon$.
Therefore, by the squeeze theorem, $lim_{p \to \infty} \Vert x \Vert_{l^p} = \Vert x \Vert_{l^\infty}$.

NOTES
$l^1$ is the space of **all absolutely summable sequences** of real or complex numbers. 
$||x||_{l^\infty}$ is read as the $l$-infinity norm of $x$.
This result extends the finite-dimensional fact that $||x||_{l^p} \to ||x||_{l^\infty}​$ as $p \to \infty$ to infinite sequences in $l^1$, showing how $l^p$-norms approximate the supremum norm.
The proof uses tail estimates from the $l^1$ condition, Minkowski’s inequality, and the boundedness of $||x||_{l^p}$ by $||x||_{l^1}​$​ to approximate the infinite norm using finite truncations of the sequence.
The argument relies on approximating infinite-dimensional behavior with finite-dimensional results, then passing to the limit using the squeeze theorem.
